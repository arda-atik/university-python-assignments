# 🎓 University Python Assignments 

This repository contains a collection of algorithmic problems, mathematical modeling exercises, and data processing tasks completed during my Mathematical Engineering studies.

## 🚀 Projects Overview

| File Name | Description | Key Concepts Demonstrated |
|-----------|-------------|---------------------------|
| `tropic_of_cancer_voyage.py` | Calculates Earth circumnavigation time along the Tropic of Cancer. | Trigonometry, Mathematical Modeling |
| `collatz_sequence_analyzer.py` | Analyzes specific terms and behaviors in the Collatz conjecture. | Algorithmic Logic, While Loops |
| `prime_number_operations.py` | Calculates the sum of prime numbers within given intervals. | Prime Algorithms, Helper Functions |
| `koch_snowflake_fractal.py` | Computes the perimeter of a Koch snowflake fractal. | Recursion, Fractals |
| `meteorological_data_analysis.py` | Analyzes historical weather data for meaningful patterns. | Tuples, Data Iteration |
| `flight_ticket_analyzer.py` | Processes and validates complex flight ticket datasets. | Dictionaries, Sets, Data Validation |
| `czech_license_plate_validator.py` | Validates license plates against complex categorical rules. | String Manipulation, Nested Logic |
| `parrot_speech_analysis.py` | Analyzes text to find shared vocabularies and word counts. | Text Parsing, Sets, Custom Sorting |
| `geospatial_coordinate_analysis.py` | Calculates distances using the Haversine formula. | Exception Handling (`try-except`), Math |
| `temperature_data_processor.py` | Reads, sorts, and writes CSV temperature data efficiently. | File I/O, Data Parsing, Sorting |
